# 界面设计说明

听宇，听见宇宙。界面是一片夜空：节目封面的颜色会染进背景的星云，侧栏、播放栏和弹窗都是悬浮在星云上的毛玻璃。深色是「深空」，浅色是同一片天空的「晨曦」，跟随系统切换。

界面全部用 mygo 的原生 UI 绘制（`internal/ui`），不嵌网页。这份文档说明设计的约定，改界面时照着它，新加的东西就能和原有的放在一起不违和。

## 布局

```text
┌──────────────┬───────────────────────────────────────────┐
│ 侧栏（玻璃）  │  页面：发现 / 节目详情 / 正在播放            │
│ 标志 · 导航   │                                           │
│ 我的订阅      │                                           │
│ 最近播放      │                                           │
│ 设置  ⌘,     │                                           │
├──────────────┴───────────────────────────────────────────┤
│ 播放栏（玻璃胶囊）：封面 · 控制 · 进度 · 倍速 · 展开          │
└──────────────────────────────────────────────────────────┘
```

- 窗口隐藏了标题栏（`TitleBarHidden`），系统的红绿灯按钮压在侧栏上。侧栏顶部的标志和每页顶部的那一条可以拖动窗口，双击会缩放窗口。
- 侧栏宽 244，离窗口边缘 10。播放栏横跨整个窗口，在侧栏下面，所以设置入口永远在播放栏上方。界面测试会检查这一点。
- 打开「正在播放」时播放栏会收起，播放页占满侧栏右边的区域。
- 播放出错、缓冲中、进度保存失败时，提示以玻璃胶囊的形式浮在播放栏上方，不占页面空间。

## 颜色

颜色定义在 `style.go` 的 `palette` 里，每一帧按系统的深浅色取一次。界面代码只用这些名字，不直接写色值。

| 名字 | 用途 | 深色 | 浅色 |
| --- | --- | --- | --- |
| `void` | 星云下面的底色 | `#05040b` | `#f5f3fc` |
| `panel` / `panelHi` | 卡片、输入框；悬停时 | 白 4.5% / 8.5% | 白 62% / 86% |
| `rim` | 面板的细边框 | 白 9% | `#281e5a` 10% |
| `solid` | 不透明的面，用于弹窗 | `#110f1d` | `#fcfbff` |
| `text` / `muted` / `faint` | 正文 / 次要 / 更弱 | `#f4f2ff` / `#aaa6c8` / `#6c6889` | `#15122a` / `#5d5878` / `#9a96b4` |
| `accent` | 主色，极光的紫 | `#8b6dff` | `#6a4cff` |
| `cyan` / `rose` | 极光的青和玫红 | `#3fd5f0` / `#f472b6` | `#0ea5c6` / `#e0458f` |
| `danger` / `ok` / `warn` | 错误 / 成功 / 提醒 | `#ff6b8a` / `#4ade9c` / `#fbbf5a` | `#e11d48` / `#059669` / `#d97706` |

- **极光渐变**（`aurora`）由紫过渡到青，只给最重要的东西用：播放按钮、主操作按钮、进度条已播放的部分、选中状态。一个页面里不要用太多处。
- **光环**（`halo`）是首尾相接的紫、青、玫红，用在会转的环上，比如搜索时的输入框边框。
- **节目色**：每个节目从封面取一个颜色（`vibrant`）。它取的是鲜艳像素里最多的那种色相，不取平均色，因为平均色大多发灰；太暗的颜色会提亮。封面还没下载好时，用标题算出一个固定色相。节目色用于星云、封面光晕、卡片悬停时的发光和作者名。
- mygo 的主题（`Theme`）也会跟着改：控件自带的颜色、焦点环和选中色都换成上面这些颜色。

## 文字

用系统字体。字号随层级拉开，不靠颜色区分：

| 用途 | 字号 | 其他 |
| --- | --- | --- |
| 页面标题（发现） | 40 | 粗体，字距 -0.5 |
| 节目标题 | 32 | 粗体，最多两行 |
| 正在播放的单集标题 | 24 | 粗体，居中，最多两行 |
| 区块标题（单集、搜索结果） | 17–18 | 粗体 |
| 正文 | 13–15 | |
| 辅助信息 | 11–12 | `muted` 或 `faint` |
| 小标题（DISCOVER、PODCAST、NOW PLAYING） | 11 | 粗体，字距 2.2，大写英文，配一个小图标 |

时长、进度、计数这类数字都用等宽数字（`FontFeatures("tnum")`），这样数字变化时宽度不会跳。

## 动效

三种弹簧动画，定义在 `style.go`：

| 名字 | 参数 | 用在哪 |
| --- | --- | --- |
| `glide` | 420 ms，回弹 0.08 | 翻页、封面飞行、侧栏的选中光条 |
| `pop` | 320 ms，回弹 0.28 | 按钮按下和悬停、图标变形、小元素出现 |
| `rise` | 600 ms，回弹 0.12 | 正在播放页升起，播放栏进出 |

主要的动效：

- **翻页**：新页面从下方 18 处淡入，旧页面原地淡出。
- **共享元素**：点开节目时，被点击的那张封面（结果卡片或侧栏条目）飞到详情页的大封面位置；展开和收起播放页时，封面在播放栏和「行星」之间来回飞。为了不在同一帧里出现两个相同身份的元素，只有鼠标悬停或获得焦点的那张封面才带身份（`coverMatch`）。
- **侧栏选中光条**：同一时间只有一条，换选中项时它滑过去（`navMatch`）。
- **搜索结果**：卡片按顺序逐张浮现，每张间隔 40 ms，最多错开 12 张。鼠标悬停时卡片抬起 6、放大 3%，并泛出节目色的光。
- **榜单**：「发现」页没有搜索时，推荐词缩成一行，下面是「大家在听」：Apple 播客中国区榜单，卡片和搜索结果是同一种，封面左上角标着名次。前三名的名次用极光渐变，其余用深色半透明底。榜单没加载出来时，还是原来那个转动的小行星系。
- **播放 / 暂停**：两个图标旋转着互相变形；缓冲时按钮外有一圈转动的弧线。
- **订阅成功**：「已订阅」标签弹出来，同时迸出一圈星尘（0.9 秒）。
- **正在播放**：
  - 封面缓慢地放大、缩小，像在呼吸。
  - 一颗「卫星」沿轨道标出播放进度。
  - 封面周围的 96 根光晕柱，高度跟着真实响度变化，见下文「响度」一节。

**减弱动态效果**：系统打开「减弱动态效果」时，界面不再有位移、缩放和持续的动画（星云、光晕、音柱、轨道里的小行星），颜色变化保留，只做淡入淡出。表示「正在进行」的指示（搜索时转动的边框、缓冲时的转圈）照常转动，和系统自己的加载指示一样。自己写的动画都要读 `c.Preferences().ReduceMotion`。

## 星云背景

`cosmos.go` 加上着色器 `nebula.kage`。

- 星云是用分形噪声互相扭曲、层层叠出来的云团，由三种颜色组成：节目色、紫和青。向窗口边缘逐渐变暗，深色模式下还会叠上 140 颗闪烁的星点。
- 云团在窗口 1/5 大小的画布上绘制，再拉伸铺满窗口。云本身是柔和的，拉伸看不出损失，GPU 的工作量却能省掉绝大部分。
- **只在播放时流动**，每秒 30 帧。暂停后保持静止，什么都不重画；下次播放时从停下的地方接着流动。节目色变化时会用 1.2 秒渐变过去。
- 播放时，云的亮度会跟着响度变化（`Pulse`）。
- 没有 GPU 时（包括界面测试里的 `ui.Tester`）不运行着色器，改画一层渐变。

## 响度

正在播放页的光晕和星云的亮度，都跟着正在播放的声音大小变化。

- `mygoengine` 在解码时测量响度：每 1024 帧一块（44.1 kHz 下约 23 ms），算出均方根后映射到 0–1，0 对应 -50 dB 及以下，1 对应 0 dB。结果写进一个无锁环形缓冲（`player.Meter`），按起始帧编号存放，在音频线程上记录时既不加锁也不分配内存。
- 解码会跑在实际播放前面，所以界面查的是「正在被听到的那个位置」的响度。这样提前解码、调倍速和拖动进度后，画面和声音依然对得上。
- 界面上的数值像电平表的指针：声音变大时立刻跟上（时间常数 30 ms），变小时慢慢落下（250 ms）。
- 光晕的波形一直按时间流动，响度只决定光晕有多高。引擎测不了响度时（比如测试用的假引擎），光晕改用一种模拟说话起伏的动画。系统打开了「减弱动态效果」时，光晕静止，星云也不随声音变亮。

## 图标

`icons.go` 里是一套自绘图标：24 的网格，线宽 1.8，圆角端点和圆角拐角，颜色取 `currentColor`，跟随所在文字的颜色。新加图标时照这个规格画，写成一个 `icon(...)` 变量。按钮里只放图标、不放文字时，要给按钮设置 `Label`，这样读屏软件和测试都能找到它。

应用的标志是一颗带光环的行星，光环的远端在行星后面、近端在前面，右上角有一颗四角星。它画在 `brand.go` 里：侧栏左上角的小标志和应用图标都用这一份代码。修改后重新生成图标：

```bash
go run ./tools/icon
```

生成的图标遵循 macOS 图标网格：1024 的画布里，主体占 824，四周留出阴影的位置。

## 性能约定

- 一直在动的东西（星云、光晕、音柱、骨架屏的扫光、轨道里的小行星）都放在 `Draw` 里，用 `p.Now()` 计算位置。这些帧只需要重绘，不用重新构建整个界面。
- 这类动画都要检查 `p.Accelerated()`：没有 GPU 时停在静止画面。界面测试的渲染器也走这条路，所以测试不会被持续的动画拖慢。
- 每帧都在移动的小圆点（「发现」页轨道上的小行星、播放页轨道上的「卫星」）用 `dot` 画成路径，不用 `Fill`。`Fill` 会把矩形的边对齐到整像素，好让面板的边清晰；但小圆点移动时就会一格一格地跳，沿扁椭圆走时看起来像在上下抖。路径落在像素之间时会做平滑。轨道上的小行星每秒画 60 帧。
- 播放时界面每秒重新构建 4 次，用来更新时间和进度条，因为它们每隔几秒才会移动一个像素。
- 悬停、按下这类动画用 `AnimatePose`，播放过程中只重绘、不重新构建界面。
- 模糊的封面背景加了 `Cache()`，只渲染一次。
- 封面下载后缩小到 640 像素以内（最大的封面是 280 点的行星，Retina 上要 560 像素）。RSS 里的原图常有 1400 到 3000 像素，解码后每张 8 到 36 MB；缩小后不到 2 MB。内存里最多留 120 张，最久没用的先放掉，磁盘上的缩小版让它们很快就能回来。

## 测试依赖的文字

界面测试（`internal/ui/*_test.go`）是按界面上的文字和 `Label` 找元素的。改文案时要留意下面这些：

- 「听宇」「我的订阅」「还没有订阅」「没有正在播放的单集」「设置」
- 搜索框的 Label「搜索播客」，搜索按钮「搜索」
- 「订阅这个节目」「取消订阅」「无法保存订阅」
- 「大家在听」「Apple 播客 · 中国区榜单」「宇宙很大，从一个关键词开始」
- 播放按钮的 Label「播放」「暂停」，以及「无法保存播放进度」
- 设置弹窗里的「API Key」「API Secret」「显示密钥」「保存」「关闭」

## 文件

| --- | --- |
| `style.go` | 颜色、渐变、动效参数、格式化函数 |

| `cosmos.go` · `nebula.kage` | 星云背景、星点、响度的平滑 |
| `sidebar.go` | 侧栏、导航、订阅和最近播放 |

| `icons.go` · `brand.go` | 图标和标志 |
