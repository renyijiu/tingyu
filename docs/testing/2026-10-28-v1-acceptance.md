## 复测步骤

在仓库根目录运行：

```bash
go test -race -cover ./...
go vet ./...
```

用独立目录启动原生窗口，后续重启继续使用同一个目录：

```bash
export TINGYU_DATA_DIR="$(mktemp -d /tmp/tingyu-acceptance.XXXXXX)"
go tool mygo dev
```

1. 搜索故事FM并订阅，确认侧栏显示节目，RSS 单集列表加载完成。
2. 播放上文的短音频样本，依次验证进度推进、暂停、点击跳转和手动拖动。真实节目列表会变化，必要时选用另一集受支持的短音频。
3. 跳到结尾附近，等待播放结束；再次播放，确认从头开始。
4. 播放期间搜索 TED Talks Daily 并打开详情，确认浏览节目不影响当前播放。
5. 将音频暂停在中间位置，退出应用。在同一终端中再次运行 `go tool mygo dev`，保持 `TINGYU_DATA_DIR` 不变。
6. 确认订阅仍在、单集显示已保存进度；点击该集，确认从保存位置续播。
7. 取消订阅，确认侧栏更新，并检查隔离目录中的 `library.json` 仍保留该集播放进度。

本次系统音频输出、真实服务集成、受控 HTTP 异常和大列表 UI 的额外验证使用了会话临时审计程序。这些程序尚未作为可移植测试套件纳入仓库，因此上面的 `go test` 命令不会执行表中所有现场验收场景。
