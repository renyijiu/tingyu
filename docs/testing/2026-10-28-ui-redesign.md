原生窗口的截图用的是一个会话里临时写的驱动程序：它用真实的 iTunes 搜索和 RSS，但播放器换成假引擎，只模拟播放位置、不出声，截图后就从仓库删掉了。所以表里「播放」一项验证的是界面状态，不是声音。

## 尚未验证与已知限制

1. **光晕和星云跟随真实响度**（`179ab2f`）：响度测量有单元测试（按帧查找、拖动后取新数据、记录时不分配内存），但上面的窗口截图是在这个提交之前拍的，用的假引擎也测不了响度。光晕和星云在真实播放时跟不跟得上声音，还没有用眼睛确认过。
2. **真实音频播放**：改版没有改播放逻辑，但这一轮没有在新界面里用真实 MP3 重测播放、拖动和续播。可以按首版的复测步骤来做。
3. **键盘与辅助功能**：没有检查 Tab 焦点顺序和焦点环，也没有在原生窗口里打开「减弱动态效果」和「增强对比度」检查。
4. **最小窗口的原生渲染**：860×560 只在无窗口截图里检查过。
5. **耗电**：星云只在播放时以每秒 30 帧重画，暂停时不重画。但没有测过长时间播放时的 GPU 和电量占用。
6. **窗口被遮挡**：窗口被其他窗口完全挡住时，mygo 会暂停绘制帧，翻页和封面飞行会停在半途，窗口重新露出后继续。这是框架本身的行为，不是缺陷，但截图时要让窗口保持在前台。

## 复测步骤

自动测试：

```bash
go test -race ./...
go vet ./...
```

用独立数据目录启动原生窗口：

```bash
export TINGYU_DATA_DIR="$(mktemp -d /tmp/tingyu-ui.XXXXXX)"
go tool mygo dev
```

1. 发现页空态：中间是一个转动的小行星系，下面的推荐词点一下就会搜索。没有密钥时，搜索框下面有一条 iTunes 提示，点它会打开设置。
2. 搜索「故事FM」：搜索框的边框转一圈极光，结果卡片逐张浮现；鼠标悬停时卡片抬起，并泛出封面的颜色。
3. 点一张卡片：封面从卡片飞到详情页的大封面位置，背景星云换成这个节目的颜色。订阅：「已订阅」标签弹出，同时迸出一圈星尘，侧栏「我的订阅」出现这个节目。
4. 播放一集：播放栏的按钮变成暂停，单集行和侧栏出现跳动的音柱，星云开始缓慢流动。暂停后星云静止。
5. 点播放栏的封面或右端的展开按钮：封面飞成圆形「行星」，外圈轨道显示进度；有人说话时光晕升高，停顿时回落。切换倍速时，高亮胶囊滑到新的选项上。
6. 收起：封面飞回播放栏，播放栏重新升起。
7. 在「系统设置 → 辅助功能 → 显示」打开「减弱动态效果」：星云、光晕和卡片的抬起都停下，颜色变化仍然保留。
8. 切换系统的深浅色：界面在「深空」和「晨曦」之间切换，深色模式下有星点。
9. 把窗口缩到最小（860×560）：设置入口仍在播放栏上方，正在播放页的行星会跟着缩小，内容不会被裁掉。
